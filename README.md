# Laboratórios AWS Solutions Architect Associate

Repositório dedicado ao armazenamento e documentação dos laboratórios práticos e estudos para a certificação **AWS Certified Solutions Architect - Associate**, desenvolvidos durante o programa de capacitação da **Escola da Nuvem** (Turma C10 OUT - DPCN 19).

## 🚀 Sobre o Repositório

Este espaço tem como objetivo registrar minha jornada de aprendizado na nuvem da AWS, servindo como portfólio prático de arquitetura de soluções, anotações e resolução de desafios propostos no curso.

## 📚 Estrutura

* `labs/`: Passo a passo e documentação dos cenários práticos em nuvem.
* `notes/`: Resumos de conceitos, padrões de arquitetura e dicas para o exame.

## 🛠️ Tecnologias e Serviços Abordados

* **Computação:** Amazon EC2, AWS Lambda, Auto Scaling, Elastic Load Balancing (ELB)
* **Armazenamento e Banco de Dados:** Amazon S3, Amazon EBS, Amazon EFS, Amazon RDS, DynamoDB
* **Redes e Entrega de Conteúdo:** Amazon VPC, Route 53, Amazon CloudFront
* **Segurança e Governança:** IAM, AWS Shield, KMS, CloudWatch, CloudTrail

## 🎯 Objetivo

Desenvolver competências reais em arquitetura de nuvem e conquistar a certificação oficial AWS Certified Solutions Architect - Associate.
