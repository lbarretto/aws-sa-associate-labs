# AWS Solutions Architect Associate - Labs

Hands-on labs and documentation for my AWS Certified Solutions Architect - Associate journey, developed during the **Escola da Nuvem** training program (Class C10 OUT - DPCN 19).

## 🚀 About This Repository

This repository serves as a centralized portfolio for my practical exercises, architectural diagrams, and study notes as I prepare for the official AWS Certified Solutions Architect - Associate (SAA-C03) exam.

## 📚 Structure

* `labs/`: Step-by-step documentation of practical cloud scenarios.
* `notes/`: Key takeaways, architecture patterns, and exam tips.

## 🛠️ Technologies & Services Covered

* **Compute:** Amazon EC2, AWS Lambda, Auto Scaling, Elastic Load Balancing (ELB)
* **Storage & Database:** Amazon S3, Amazon EBS, Amazon EFS, Amazon RDS, DynamoDB
* **Networking & Content Delivery:** Amazon VPC, Route 53, Amazon CloudFront
* **Security & Governance:** IAM, AWS Shield, KMS, CloudWatch, CloudTrail

## 🎯 Objective

To build real-world cloud architecture skills and successfully achieve the AWS Certified Solutions Architect - Associate certification.
